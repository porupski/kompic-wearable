## Card Detect (CD) pin

**Physical presence:** Yes — dedicated "Cd" pin in PCB layout, separate from the 8 signal contacts. Pin 2 is dual-function CD/DAT3. [p. 1, drawing]

**Active polarity when card inserted:** **NOT stated in this datasheet.** No logic level, pull direction, or switch type described.

**Convention (unverified):** Most push-push TF sockets use a normally-closed switch that opens when a card is inserted (Cd goes HIGH with pull-up when absent, LOW when inserted). This is an unconfirmed assumption for this specific part — **bench verification is mandatory before writing card-detect firmware.**

**Firmware impact:** In iv7.1, SD_Cd is listed as "test pad only" (not on a GPIO). Hot-swap detection is therefore not implemented. This is acceptable for v1 if the card is treated as fixed storage during operation.

## SDMMC protocol context (1-bit mode)

### Why 1-bit was chosen
GPIO budget is exhausted. Only GPIO38 (CLK), GPIO39 (CMD), GPIO40 (DAT0) are available. DAT1–DAT3 not assigned. 4-bit mode is physically impossible without a hardware spin. The socket supports 4-bit mechanically. [iv7.1 pinout; p. 1 pin table]

### Pull-up requirements [SD spec]

| Signal | Pull-up required | Recommended value | Kompic v7.2 | Status |
|---|---|---|---|---|
| SD_CLK (GPIO38) | Optional | 10–100 kΩ | 10 kΩ | Consistent |
| SD_CMD (GPIO39) | Mandatory | 10–100 kΩ | 10 kΩ | Correct |
| SD_DAT0 (GPIO40) | Mandatory | 10–100 kΩ | 10 kΩ | Correct |
| SD_DAT1–DAT3 | Required if used | 10–100 kΩ | Not connected | Card has internal weak pull-ups on unused DAT lines in 1-bit mode |

Pull-ups must be to SD VDD rail (3.2V in Kompic).

### Maximum clock frequency (1-bit mode) [SD spec]

| Speed mode | Max clock | Bus width | Notes |
|---|---|---|---|
| Default Speed (DS) | 25 MHz | 1-bit or 4-bit | Mandatory baseline; all SD cards support |
| High Speed (HS) | 50 MHz | 1-bit or 4-bit | Requires CMD6 negotiation; most modern microSD support |
| UHS-I (SDR50/104/DDR50) | 100–208 MHz | 4-bit only | Not available in 1-bit mode |

**Practical limit for Kompic:** 50 MHz (HS 1-bit). Note: 10 kΩ pull-up × ~20 pF line capacitance → RC ≈ 200 ns — too slow for 50 MHz HS recovery. See WARN-02.

### Initialization sequence (1-bit SDMMC, ESP-IDF) [SD spec / ESP-IDF]

```
1. Apply VDD; CMD and DAT0 held high by pull-ups.
2. Wait ≥1 ms for card power-up.
3. Send ≥74 clock cycles with CMD high (card initialization clocks).
4. CMD0 (GO_IDLE_STATE) — reset card.
5. CMD8 (SEND_IF_COND) — detect SD v2.0+ vs legacy.
6. ACMD41 (SD_SEND_OP_COND) — repeat until card not busy.
7. CMD2 (ALL_SEND_CID), CMD3 (SEND_RELATIVE_ADDR) — get RCA.
8. CMD7 (SELECT_CARD) — transition to Transfer state.
9. ACMD6 (SET_BUS_WIDTH) with arg 0b00 — FORCE 1-bit mode.
   DO NOT send 0b10 (4-bit) — DAT1–DAT3 not wired.
10. (Optional) CMD6 (SWITCH_FUNC) — negotiate High Speed 50 MHz.

ESP-IDF: set sdmmc_slot_config_t.width = 1 and
SDMMC_HOST_FLAG_1BIT to enforce 1-bit throughout.
```

### Hot-swap safety
Push-push mechanism allows physical removal at any time. Card removal during active I/O corrupts the filesystem (FAT/FAT32 has no journaling). Firmware must either unmount before removal or detect the CD transition and flush/unmount cleanly. With CD currently on a test pad (no GPIO), hot-swap safety is by user convention only: do not remove the card while the device is logging. [SD spec / ESP-IDF]

## Warnings & Errata

| ID | Title | Impact | Notes |
|---|---|---|---|
| W-01 | CD pin polarity undetermined | MEDIUM | Datasheet gives no information on CD switch logic level. Open Issue #4 in iv7.1 remains unresolved. Do not write card-detect firmware until bench-confirmed. |
| W-02 | 10 kΩ pull-ups too slow for 50 MHz HS mode | HIGH | 10 kΩ × ~20 pF ≈ 200 ns RC — far too slow for 50 MHz CMD recovery. Use Default Speed (25 MHz) with 10 kΩ, or reduce pull-ups to 4.7 kΩ and verify signal integrity at 50 MHz with scope. |
| W-03 | DAT1–DAT3 not connected — must enforce 1-bit in driver | HIGH | If ESP-IDF SDMMC host is initialised without `width = 1`, it will attempt 4-bit via ACMD6 → bus corruption on unwired lines. Always set `sdmmc_slot_config_t.width = 1`. |
| W-04 | No GPIO for CD pin | LOW | CD is a test pad only. Hot-swap detection impossible without hardware change. Treat SD card as fixed storage during operation. |

## Open questions

1. **CD pin polarity** — LOW or HIGH when card inserted? Measure on bench with multimeter before writing card-detect logic. (iv7.1 Open Issue #4.)
2. **Contact capacitance** — Not in datasheet. Obtain from Shenzhen Shouhan or measure if 50 MHz HS mode is desired.
3. **Pull-up values for HS mode** — Reduce CMD/DAT0 pull-ups from 10 kΩ to 4.7 kΩ or 2.2 kΩ if 50 MHz HS is needed; verify with oscilloscope.
4. **LCSC part number** — Confirm BOM part number matches this drawing's PCB footprint (8.00 mm mounting hole pitch, 1.10 mm contact pitch) before ordering.
5. **Filesystem journaling** — FAT32 has no journaling; hot-swap corruption risk. Consider exFAT (ESP-IDF v5+) or a "safe to remove" UI indicator.
6. **4-bit upgrade path** — For Kompic Mk II with more GPIOs: route DAT1–DAT3 and this socket supports 4-bit 50 MHz (4× throughput). Worth routing in next spin if fast data logging is needed.
