|---|---|---|

| 1 | OVER_TEMP | Latching over-temperature flag. Clears on read. |
| 0 | OC_DETECT | Latching overcurrent flag. Clears on read. |

|---|---|---|

| 2:0 | MODE[2:0] | 0=Internal trigger (GO bit); 1=External trigger edge; 2=External trigger level; 3=PWM/analog; 4=Audio-to-vibe; **5=RTP real-time**; 6=Diagnostics; **7=Auto-calibration** |

### RATED_VOLTAGE — 0x16 [p. 44]

Sets full-scale reference voltage. Must be written before calibration.

```
RATED_VOLTAGE = V_rated_RMS / 20.58e-3
Example: 1.0 V_RMS → 1.0 / 0.02058 ≈ 49 = 0x31
```

(Simplified; use full formula from p. 44 with SAMPLE_TIME correction for accuracy.)

### OD_CLAMP — 0x17 [p. 44]

Maximum overdrive/clamp voltage. Must be > RATED_VOLTAGE. Typical: 1.5–2× RATED_VOLTAGE.

```
V_clamp(V) = 21.22e-3 × OD_CLAMP
Example: If RATED_VOLTAGE=0x31 (49), OD_CLAMP = 0x4A–0x62 gives 1.5–2× headroom
```

## Initialization sequence

### LRA mode with auto-calibration

```
1. Wait ≥ 250 µs after VDD ramp-up.                                    [p. 59]
2. Drive GPIO0 HIGH (EN). Wait ≥ 1.5 ms for device ready.              [p. 6–7]
3. Write 0x07 to 0x01  — exit standby, enter calibration mode.         [p. 29, 37]
4. Write 0x1A = 0xB6   — N_ERM_LRA=1, FB_BRAKE_FACTOR=3x, LOOP_GAIN=High, BEMF_GAIN=15x
5. Write RATED_VOLTAGE to 0x16  — motor-specific, see formula above.   [p. 29, 44]
6. Write OD_CLAMP to 0x17      — motor-specific, see formula above.    [p. 29, 44]
7. Write 0x1E = 0x30   — AUTO_CAL_TIME=3 (1000–1200 ms, most accurate) [p. 29, 52]
8. Write 0x1B per DRIVE_TIME calculation — initial resonant freq guess. [p. 29, 47]
9. Write 0x01 to 0x0C  — GO=1, start calibration.                      [p. 29]
10. Poll 0x0C until GO=0 (calibration complete, ~1200 ms max).         [p. 29]
11. Read 0x00: if DIAG_RESULT (bit3) = 0 → PASS. If 1 → FAIL,
    check register values and retry.                                    [p. 29, 36]
12. Write 0x00 to 0x01  — STANDBY=0, MODE=0 (internal trigger).        [p. 29, 37]
13. Write 0x06 to 0x03  — LIBRARY_SEL=6 (LRA library).                 [p. 38]
14. (Optional) Store 0x18 (A_CAL_COMP) and 0x19 (A_CAL_BEMF)
    to ESP32 NVS for restore on next boot.                              [p. 28–29]
```

### Subsequent boot (NVS calibration restore)

```
1. Wait 250 µs. Drive GPIO0 HIGH. Wait 1.5 ms.
2. Write 0x07 to 0x01  — exit standby.
3. Restore 0x1A, 0x16, 0x17 with motor values.
4. Restore stored A_CAL_COMP to 0x18, A_CAL_BEMF to 0x19.
5. Write 0x00 to 0x01  — MODE=0 internal trigger.
6. Write 0x06 to 0x03  — LRA library.
```

## Operation

### Internal trigger (MODE=0)
Write effect IDs to 0x04–0x0B, write GO=1 (0x0C). Starts within 0.7 ms [p. 7]. GO self-clears on completion. [p. 33, 39]

### Real-Time Playback (MODE=5)
Write 0x05 to 0x01, then continuously write amplitude to 0x02 (RTP_INPUT). Signed by default: 0x7F=full+, 0x00=zero, 0x81=full−. Useful for streaming custom waveforms from PPG data. [p. 33, 38]

### LRA resonance monitor
Read 0x22 (LRA_PERIOD) during active playback to get live resonant period:
```
f_LRA (Hz) = 1 / (LRA_PERIOD[7:0] × 98.46 µs)   [p. 12, 54]
```

## Datasheet notes

- DEVICE_ID = 7 (0b111). Always verify at startup — DRV2605 (non-L) returns ID=3. [p. 36]
- Auto-calibration results (0x18 A_CAL_COMP, 0x19 A_CAL_BEMF) should be stored in NVS and restored each boot to avoid the 1.2 s calibration delay. [p. 28–29]
- OTP programming (registers 0x16–0x1A) requires VDD 4.0–4.4 V and is one-time irreversible. [p. 29]
- I2C watchdog: 4.33 ms in active mode. In standby, bus hang needs power-cycle to recover. [p. 19]
- Brownout protection: VDD ramp rate must exceed 3.6 kV/s for clean reset. [p. 20]
- Output PWM is trinary-modulated at 20.5 kHz; no external filter or ferrite needed. [p. 1, 7, 18]
- 1 µF (X5R/X7R) required on VDD and REG pins; 0.1 µF low-ESR on VDD recommended. [p. 57]
- IN/TRIG must be tied to GND if unused (added in Revision B). [p. 4]
- STANDBY immediately stops any playing waveform. [p. 21]
- LRA auto-resonance tracks motor frequency in real-time without requiring re-calibration. [p. 12]
- Device auto-switches to open-loop if back-EMF is not detected (e.g., motor unplugged). [p. 12]

## Open questions

1. **ELV1411A parameters:** Rated voltage (V_RMS), resonant frequency (Hz), coil impedance (Ω) — required for RATED_VOLTAGE and DRIVE_TIME. Source datasheet or measure.
2. **IN/TRIG PCB connection:** Is ball B1 tied to GND on the Kompic Mk I PCB? Verify in KiCad schematic. If floating, a hardware fix is needed before bring-up.
3. **LRA effect ID characterisation:** After hardware bring-up, iterate through IDs 1–123 with ELV1411A and log feel + duration for a firmware effect table.
4. **Auto-calibration vs NVS restore strategy:** Run calibration on every cold boot (~1.2 s delay) or only when NVS is empty? OTP option requires temporary 4.0–4.4 V boost — available in factory test?
5. **RTP streaming latency:** End-to-end latency from PPG beat detection to haptic output. 0.7 ms GO start-up + I2C bus time are datasheet floors; scheduling latency needs measurement.
6. **DRV_EN during deep sleep:** GPIO0 can retain output state in RTC domain. Decide whether to hold EN=HIGH (retain standby, 4 µA) or EN=LOW (full shutdown, 4 µA shutdown) during deep sleep. No functional difference in current at those levels but shutdown drops register state and requires full re-init on wake.
