**Bus 1 worst-case node count: 9 devices.** With 10 kΩ pull-ups and typical ~10 pF per stub, total C_bus ≈ 90 pF — within I2C 400 pF limit. If ESDALCL5-1BM2 ESD diodes are placed on bus lines, add 26–30 pF per protected line; verify total stays under 400 pF.

**Address conflict risk:** VEML6030 at 0x48 (ADDR=VDD) collides with TMP117 at 0x48 (ADD0=GND). Ensure address strapping places them on different addresses: VEML6030 at 0x10 (ADDR=GND) OR TMP117 at 0x49+ before assembly.

## RTC GPIO wake sources

The PCF85063A INT pin and select GPIOs support deep-sleep wake. Only GPIOs in the RTC power domain can wake the ESP32-S3 from deep sleep.

| GPIO | Signal | Wake-capable | Notes |
|------|--------|-------------|-------|
| GPIO6 | BME688 INT / spare | Yes | RTC domain confirmed |
| GPIO7 | VEML6030 INT / spare | Yes | RTC domain confirmed |
| GPIO8 | TMP117 ALERT | Yes | RTC domain confirmed |
| GPIO15 | RTC_INT (PCF85063A) | Yes | Primary RTC alarm wake source |
| GPIO16 | BQ_QON button | Yes | Button wake from deep sleep |
| GPIO21 | Encoder A (EC05E) | Yes | Crown rotation wake |

**Not wake-capable (cannot wake from deep sleep):**
- GPIO38 (SD_CLK), GPIO39 (SD_CMD), GPIO40 (SD_DAT0) — no RTC
- GPIO43 (Encoder B) — no RTC wake capability
- GPIO47 (Mic_CLK), GPIO48 (Mic_Dout) — no RTC
- GPIO41 (Flashlight) — no RTC

**Deep sleep strategy:** use RTC_INT (GPIO15) as primary timer wake; GPIO16 (button) for user wake; GPIO21 (encoder) for crown-turn wake.

## Firmware bring-up checklist (derived from all extracts)

### Boot-time initialisation order (critical sequencing)

1. **TPS62840 always on** — 3.2V rail present at boot. No action.
2. **XC6206 always on** — 1.8V rail present when 3.2V is present. No action.
3. **BQ25619 I2C init** (Bus 2, 0x6A) — read REG_STATUS (0x08) for PG_STAT; configure OTG/boost if needed.
4. **PCF85063A I2C init** (Bus 1, 0x51) — check OS bit in Seconds register; if set, RTC lost power, re-set time.
5. **LSM6DSV16X I2C init** (Bus 1, 0x6A/6B) — verify WHO_AM_I=0x70; configure CTRL1/CTRL2, INT1.
6. **LIS3MDLTR I2C init** (Bus 1, 0x1C/1E) — configure continuous mode; reload hard-iron offsets from NVS.
7. **MAX30101 I2C init** (Bus 1, 0x57) — write REG_MODE_CONFIG=0x40 (reset); configure SpO2 mode.
8. **BME688 I2C init** (Bus 1, 0x76/77) — use BSEC library; configure gas heater sequencer.
9. **TMP117 I2C init** (Bus 1, 0x48+) — configure 1 Hz conversion; set alert thresholds.
10. **VEML6030 I2C init** (Bus 1, 0x10) — configure ALS gain and integration time.
11. **DRV2605L I2C init** (Bus 2, 0x5A) — set GO=0; mode=5 (RT playback) or mode=0 (internal); LRA library=6; verify auto-cal results or re-calibrate.
12. **MAX-M10S I2C init** (Bus 1, 0x42) — configure UBX protocol; set power mode; configure 1PPS.
13. **SD card mount** (SDMMC, GPIO38/39/40) — `sdmmc_slot_config_t.width = 1`; mount on demand only.
14. **PDM mic** (I2S PDM RX, GPIO47/48) — enable I2S peripheral with 3.072 MHz CLK → 48 kHz PCM; discard first 20 ms.
15. **CO5300 display** (QSPI, GPIO35/36/37/10/11/12) — apply power-on sequence; clear GRAM; send SLPOUT.
16. **CST9217 touch** (I2C Bus 1) — configure gesture mode; enable INT.
17. **WS2812B** (RMT, GPIO9) — enable 5V boost first; GRB color order; RESET ≥ 280 µs between frames.
18. **DRV2605L auto-cal** — perform on first boot or after LRA replacement; store BEMF results in NVS.

### Sleep entry sequence

1. Flush and unmount SD card filesystem (FAT32 has no journaling).
2. Disable WS2812B (stop RMT; hold DATA low ≥ 280 µs).
3. Disable 5V boost (BQ25619 OTG_CONFIG=0) — only if not charging.
4. Stop I2S PDM clock (mic enters sleep ≤ 30 µs, draws 1 µA).
5. Place MAX-M10S in power-save mode.
6. Place BME688, LSM6DSV16X, LIS3MDLTR, TMP117, VEML6030 in sleep/standby.
7. MAX30101: write MODE_CONFIG reset or set SHDN bit.
8. Set ESP32-S3 deep sleep wake sources: GPIO15 (RTC_INT), GPIO16 (button), GPIO21 (encoder A).
9. `esp_deep_sleep_start()`.
