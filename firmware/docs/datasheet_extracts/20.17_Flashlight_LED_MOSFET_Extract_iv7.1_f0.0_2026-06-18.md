## Initialization / Drive Sequence

No register map — purely hardware-controlled. Firmware interaction via GPIO41 only.

```
Boot default (MOSFET off):
1. GPIO41 is INPUT (Hi-Z) at reset.
   10 kΩ pull-down holds Gate = GND → MOSFET off → LED off.

Enable flashlight:
2. Configure GPIO41 as OUTPUT.
3. Enable BQ25619 PMID boost (5 V) via I2C — wait ~100 µs for stabilization.
4. Set GPIO41 HIGH (3.2 V) → MOSFET on → LED lights up.
   Turn-on delay: td(on) typ 2.3 ns [p. 2]. Effectively instantaneous.

Disable flashlight:
5. Set GPIO41 LOW → MOSFET off → LED off.
   Turn-off: td(off) + tf typ 13.2 ns [p. 2]. Instantaneous.

PWM dimming:
6. LEDC at ≥ 1 kHz (above flicker threshold), ≤ 100 kHz (well within
   MOSFET capability: f_max ≈ Vgs/(Rg_total × Qg) ≈ 50 MHz [derived p. 2]).
   Average current = duty × I_on.
```

## Datasheet Notes

1. TJ-S4008SW4TGLCCW-A5 is a "specification for approval" document — some typical values (including Vf typical) are intentionally omitted. Validate Vf against the min/max window in production. [p. 1]
2. Vf window 2.8–3.6 V (0.8 V span at 20 mA) is unusually wide. Current-regulated drive (series resistor + fixed 5 V) is correct — it normalises brightness across the Vf spread. [p. 3]
3. Luminous intensity 6–9 lm at 20 mA [p. 3]. At 18 mA nominal ≈ 5.4–8.1 lm — a narrow-cone torch, not a room illuminator.
4. LED operating temp limit is 80 °C [p. 3]; MOSFET is 150 °C [p. 1]. The LED is the thermal weak link.
5. No dominant wavelength or color bin given beyond CCT 6000–8000 K (cool white) [p. 3].
6. Gate charge Qg = 1.1 nC [p. 2] — very low; no gate driver IC needed.
7. BSS138W body diode Vsd max 1.4 V [p. 2]. Not a concern in this topology.
