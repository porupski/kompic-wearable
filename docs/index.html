Kompic̄

/ˈkompitɕ/

Mk1b · iv8.0

An open-source, wrist-worn sensor platform.

Built to be standalone. Doesn't need a phone, an app, or the cloud — and never will.

Overview

In Active Development

Kompic̄ is a wearable, open-source personal device. It carries a sensor array spanning ambient conditions to biosignals — motion, environment, heart rate, skin temperature, sound, position. It's built to be standalone: no phone, no app, no cloud, no subscription. It doesn't need any of that, and it never will.

Full control over the hardware. Full control over the data. This is something you make, not something you buy — and when it breaks, you fix it.

The name is Croatian street slang: komp ("computer") plus the diminutive -ič — a "little computer," the word you'd use for an actual friend, not a stranger. Pronounced /ˈkompitɕ/ (kompich).

Currently on its second hardware revision, Mk1b (iv8.0): all ten I²C sensors bring up clean, the AMOLED display and touch panel run a working LVGL interface, and GPS streams live fixes. The bugs, the bodges, and how it got here are all on the Development page.

Author

Key Specs

  • ESP32-S3 dual-core Xtensa LX7 @ 240 MHz, 8 MB PSRAM, 16 MB flash
  • MicroSD storage (128 GB+), BLE 5.x
  • 2.06" rectangular AMOLED, 45.6 × 37.3 mm glass
  • Two 1.0 mm 4-layer PCBs: main board + skin-facing daughter board
  • Two-piece titanium case (SLM Ti-6Al-4V), ~48 × 40 × 12 mm
  • 33 g watch body, 56 g with straps
  • ~300 mAh LiPo, USB-C charging

Firmware

In Active Development

Dual-core ESP-IDF firmware: one core runs hardware drivers and sensor acquisition, the other drives the AMOLED over a DMA-based, double-buffered pipeline in PSRAM.

  • Working now — sensor drivers across the full I²C bus, LVGL 9 display + touch UI, GPS UBX/NMEA parsing with RTC time sync
  • Planned — on-device sleep staging, snore/sound classification, GPS + compass sensor fusion for a breadcrumb trail
